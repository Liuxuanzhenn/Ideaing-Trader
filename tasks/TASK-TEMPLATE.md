# 任务卡模板

复制本模板为 `T-XXX-short-name.md`，由副舵手维护状态和依赖。

```markdown
# T-XXX：任务标题

- 状态：待办
- 优先级：P0
- 对应 PRD：PRD-XXX
- 负责人：
- Reviewer：
- 计划阶段/时间：
- 分支：feat/T-XXX-short-name

## 目标

## 输入与依赖

## 文件所有权范围

## 交付接口

## 验收标准

- [ ] 验收项

## 测试命令与结果

## 风险/待决策

## 交接记录
```

状态使用：待办、进行中、待评审、阻塞、完成。涉及产品口径、公共接口或破坏性操作的任务，必须关联相应决策记录。
