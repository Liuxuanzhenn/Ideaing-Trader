# Quant Workbench

面向个人 A 股研究的量化分析与回测工作台，计划支持 Agent/MCP 接入。当前处于 Demo v1 需求评审和技术验证阶段，文档中的建议尚未全部批准。

## 项目区

- `docs/PRD-demo-v1.md`：产品范围、用户流程与验收标准
- `docs/TECHNICAL-DESIGN.md`：语言、运行形态、模块边界和技术验证建议
- `docs/DEVELOPMENT-PLAN.md`：阶段排期、Agent 角色、决策权限和合并规则
- `prototype/`：PRD 评审通过后交付的可交互 HTML 原型
- `research/`：GitHub 项目评估、数据源研究和技术验证记录
- `tasks/`：开发任务卡、负责人、依赖、分支和验收状态
- `research/REUSE-REGISTER.md`：复用项目来源、许可证、改造和验证记录
